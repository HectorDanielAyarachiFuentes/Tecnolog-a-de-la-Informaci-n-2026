# Reglas para Agentes de IA en este repositorio

1. **Lectura obligatoria inicial:**
   Antes de leer todo el código del proyecto o realizar búsquedas extensas, lee el archivo [`GUIA_IA.md`](GUIA_IA.md). 
   Contiene el desglose completo del proyecto, la función de cada archivo/carpeta y la guía de modificación rápida para ahorrar tokens y acelerar el desarrollo.

2. **Actualización OBLIGATORIA de la guía:**
   Si agregas, eliminas, renombras o modificas la función de cualquier carpeta o archivo importante dentro de este repositorio, tienes la **OBLIGACIÓN ABSOLUTA E IMPROCROSTINABLE** de actualizar el archivo [`GUIA_IA.md`](GUIA_IA.md) para mantener la documentación sincronizada al 100%.
